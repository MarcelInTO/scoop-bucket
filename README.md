# scoop-bucket

A [Scoop](https://scoop.sh) bucket for Windows builds of the tools published under
[github.com/MarcelInTO](https://github.com/MarcelInTO).

```powershell
scoop bucket add marcelinto https://github.com/MarcelInTO/scoop-bucket
scoop install glute
```

`scoop update glute` upgrades to the latest release; `scoop update *` upgrades
everything Scoop manages.

| Tool | What it is |
| --- | --- |
| [glute](https://github.com/MarcelInTO/glute) | Terminal dashboard for GitLab CI/CD pipeline and job statistics |

The manifests in `bucket/` are generated by each tool's release workflow from its
release archives and checksums, so hand edits here are overwritten by the next
release. Each manifest also carries `checkver`/`autoupdate`, so Scoop's own
`checkver -u` tooling can bump it from the GitHub release page if ever needed.
